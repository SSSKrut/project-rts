# Модель и числа

Здесь живут коэффициенты. Правится чаще всего остального; менять числа можно
свободно, менять **формы** (какие поля, какие сущности) — решением.

Мировой масштаб для калибровки: оптика пехоты 40-65 м, оптика техники 60-200 м,
радар 420-520 м, ESM 700-1400 м, стрелковое оружие упирается в 192 м, ПЗРК 900 м,
ПТУР борта 1200 м. Карта — порядка 2 км.

---

## 1. Связь

### Форма

```go
// На отряде (и на одиночной технике / борте, которые командуют собой).
type CommsState struct {
    Quality   float32  // 0..1, пересчёт раз в ~1 с
    Band      CommsBand // производная от Quality, для UI и гейтов
    Anchor    WorldPos  // точка последнего доставленного приказа
    Undelivered ecs.Entity // приказ, ждущий доставки (0 = нет)
    DeliverAt   float32    // sim-время, когда его повезут (Amber)
    Append      bool       // это был Shift-клик; решение принято при клике
}

// На юните-радисте — рация как излучатель.
type Radio struct {
    On         bool
    EmitRangeM float32
}

// На точке захвата / штабной машине.
type Relay struct {
    RangeM float32
}
```

`RadioNetwork` (существует, читателей не имеет) поглощается `CommsState`.

### Формула

```
quality = radioFactor × relayFactor × (1 - jam)

radioFactor = 1.0   живой радист в ростере с включённой рацией
              0.5   радиста нет / рация выключена   ← только «голосом», у самой точки

relayFactor = max по СВОИМ активным ретрансляторам: clamp(1 - d/R, 0, 1)
              d — расстояние от центра отряда, R — RangeM ретранслятора

jam = 0 в первой версии (место под РЭБ)
```

Ретранслятор активен, только если точка принадлежит твоей фракции и не
оспаривается.

| Источник | R |
|---|---|
| База / точка появления | 800 м |
| Захваченная точка | 450 м |
| Штабная машина | 600 м |

### Полосы и что они делают

| Quality | Полоса | Приказы | Чужие засечки | Отряд на карте | Радиус самостоятельности |
|---|---|---|---|---|---|
| ≥ 0.70 | **Связь** | мгновенно | работают | вживую | — |
| 0.40-0.70 | **Помехи** | задержка 3-8 с (линейно по quality) | не работают | вживую | — |
| 0.15-0.40 | **Обрыв** | НЕ доходят, висят как «не доставлено» | нет | последняя известная, стареет | 150 м от `Anchor` |
| < 0.15 | **Тишина** | НЕ доходят | нет | последняя известная, не обновляется | 60 м от `Anchor` |

**Ждущий приказ не отменяет текущий.** Он создаётся полностью — рисуется на
карте, стоит в инспекторе, отменяется, — но не связывается с очередью, поэтому
отряд продолжает делать то, что делал. Иначе клик во время обрыва не «ничего не
дал бы», а ОСТАНОВИЛ бы отряд, что читается хуже любого отказа. Ждать может
только один приказ: второй клик — смена намерения, побеждает свежее.

Проверка на здравый смысл: с радистом «Связь» покрывает примерно внутреннюю
треть радиуса точки, «Помехи» — до половины, дальше обрыв. Без радиста отряд
получает «Помехи», только стоя вплотную к точке. То есть смерть радиста —
не приговор, а команда «отходи к точке».

### Что делает отряд без связи

Ровно пять вещей, четыре из которых уже написаны:

1. Продолжает **последний приказ**.
2. Применяет **стоячие правила** — RoE, доктрина, поведение.
3. **Реагирует**: инстинкт выживания, перебежки, рефлексы техники и борта.
4. Не уходит дальше **радиуса самостоятельности** от `Anchor`. Цель за
   радиусом — не преследует.
5. Приказ выполнен, новых нет → **держит место и обороняется**.

Новое здесь только пункт 4.

### Рация как излучатель

Работающая рация (`On && quality > 0.15`) слышна вражеским ESM на `EmitRangeM`
и даёт **пеленг без дальности** — существующий механизм из Phase 20 M1, тем же
проходом `contact_emitter.go`, только источником становится `Radio`, а не
сенсорный канал. Базовое значение — **900 м**.

Отсюда решение игрока: выключить рацию — отряд перестаёт быть управляемым, но
пропадает с радиоразведки. Та же сделка, что «включить радар», тем же кодом и с
теми же двумя числами на одной строке в панели.

## 2. Точки захвата

```go
type ControlPoint struct {
    Radius      float32  // 25 м
    Owner       uint8    // фракция или None
    Challenger  uint8
    Progress    float32  // 0..1 в пользу Challenger
    Contested   bool
    RelayRangeM float32  // 0 = не ретранслятор
    SpawnSide   uint8    // 0 = не точка появления
}
```

- Захват **присутствием**: считаем живых наземных юнитов каждой фракции внутри
  радиуса. Борта не считаются — вертолёт точку не берёт.
- `diff = свои − чужие`; прогресс идёт со скоростью `0.10/с × min(diff,3)/3`,
  то есть одиночка берёт нейтральную точку за 10 с, трое и больше — за 3.3 с.
- Обе стороны внутри → `Contested`, прогресс заморожен, ретранслятор молчит.
- `Progress` достиг 1.0 → `Owner = Challenger`, прогресс в ноль.
- Потеря точки гасит ретранслятор: сеть в секторе проседает **в тот же тик**.
  Это главный рычаг противника против управления.

## 3. Здания

Здание — не головоломка, а объект владения.

```go
type BuildingControl struct {
    Owner     uint8
    Count     [2]uint8  // живых внутри по фракциям
    Contested bool
}
```

Считается за тик по футпринту: кто внутри — тот держит; обе стороны внутри —
оспаривается. Здание может нести `ControlPoint` (тогда точка берётся изнутри).

Приказ ровно один — **«Занять»**: зайти внутрь и рассыпаться. Внутренняя
навигация, этажи, лестницы и переходы остаются как есть — они работают и
оплачены. Уходят: распределение по окнам, посекторная зачистка (`ClearSeq`),
планировщик интерьерных позиций и матчер «кто какую берёт».

## 4. Отряд и движение

- **Строя нет.** Пехота идёт неявной россыпью (существующая `FormationLoose`,
  интервал 4 м), техника — колонной с существующим согласованием темпа.
  Выбор автоматический по составу; UI, пресетов и слотов нет.
- Отряд — 4-8 человек. Один командир, один **радист** (роль существует).
- Роли, стойки, стоячие правила, доктрины и уровни автономии — как есть.
  Новых не заводим.

## 5. Бой — заморожен в текущем виде

Урон = `база × множитель против класса × (стойка | сектор брони)`. Классы:
мягкий / лёгкий / тяжёлый / воздух. Ноль множителя = «этим по такому не
стреляем» и это же гейт выбора цели.

Механизмов разрешения выстрела **ровно три, и четвёртого не будет**:

1. **Рейкаст** — всё наземное, потолок 192 м.
2. **Аналитический воздушный** — зенитный ствол с упреждением: вероятность
   падает с дальностью и угловой скоростью.
3. **Ракета-сущность** — ПЗРК, ПТУР борта: летит, тратит топливо, срывается на
   ловушки.

Новый механизм заводится только под решение игрока, которого без него нет.

### 5.1 Баланс «пехота против техники» (пересмотр 2026-08-26)

Три сцены `lite_balance_*` держат эти числа. **Заявление — это ПАРА** открытого
поля и засады: одна зелёная сцена доказывает только, что числа тянут в одну
сторону.

| Решение | Значение | Почему так |
|---|---|---|
| `VsLight` винтовок | **0**, не «мало» | восемь стволов по 4 выстрела — 32 попадания в секунду; 0.1 от пули превращается в 90 урона/с, и отделение сносило БМП за две секунды. Ноль ещё и гейт выбора цели (`< 0.05` пропускается), так что стрелки больше не тратят очередь на корпус |
| РПГ | `VsSoft` 0.35, `VsLight` 1.6, темп 0.2 | броня — работа гранатомётчика, но ноль по пехоте делал его балластом в чисто пехотном бою (сцена `ai_mass`: 56/96 → 76/96). Предпочтение классов и так уводит его на технику, когда она есть |
| Состав мотострелкового отделения | лидер, 3 стрелка, пулемётчик, гранатомётчик, **гранатомётчик-ПТ**, **радист** | без первого отделение вообще не отвечает броне, без второго вечно живёт с половинным качеством связи (§4). Медик ушёл: лечения нет |
| Оптика пехоты | 40 м (**не тронута**) | даёт 24 м фактического первого контакта — открытый пункт, см. `PLAYTEST.md`. Подъём до 80 м делает оборону здания неприступной и требует пересборки сцен |

Замеры (`lite_balance_eyes`, обе стороны на марше): корпус видит пехоту за
**33 м**, пехота видит корпус за **127 м**, пехота видит пехоту за **24 м**.
Первое отношение — то, чего мы хотели; третье — то, что чинить отдельным
проходом.

Открытое поле: три БМП сносят отделение за ~14 с, теряя одну машину.
Засада во фланг транзитной колонне: та же цена в одну машину, но отделение
остаётся живым (7 из 8). Разница между этими строками и есть смысл засады.

## 6. Техника, авиация, ПВО — как есть

Спек-таблицы, фабрики, кинематические драйверы, рефлексы корпуса (FaceThreat /
дым и назад / бегство / GoDark), рефлексы борта (Break / Flare / Abort), радары
и ESM. Добавляется один класс: **штабная машина** — техника с `Relay{600}`,
без вооружения, дорогая цель.

## 7. Сценарий

```
missions/<name>.json
  map: "hills"
  timeSec: 900
  sides: [{ faction, controller, spawn, relayRangeM }]
  points: [{ x, z, radius, owner, relayRangeM, spawnSide }]
  forces: [{ side, atSec, kind: "squad"|"vehicle"|"air", template, x, z }]
  victory: { holdPoints: 3, ofTotal: 5, forSec: 60 }
```

Форма уже наполовину есть: `maps/<name>.json` задаёт мир, `AirArrival` — это
расписание прибытия как сущность. `forces` обобщает второе на землю.

**Победа:** держать `holdPoints` из `ofTotal` непрерывно `forSec`, либо владеть
всеми на момент истечения таймера. Экран итога с числами: точки, потери,
время под связью.

## 8. Бот

Оперативный уровень, такт 10-30 с, три глагола:

1. **Взять точку** — выбрать ближайшую нейтральную или чужую, послать
   ближайший свободный отряд.
2. **Держать точку** — оставить отряд в радиусе, RoE на свободный огонь.
3. **Ответить на потерю** — точка перешла к врагу: послать ближайший отряд
   в контратаку, если он не занят более дорогой точкой.

Оценка: `ценность точки = базовая + ретранслятор ? +0.5 : 0 + близость к своей
сети`. Никакого поиска по дереву, никаких нейросетей.

**Бот командует через ту же радиосеть**, что игрок: его приказы гейтятся его же
качеством связи. Значит по его сети можно работать — убивать радистов, резать
ретрансляторы, ловить пеленги. Симметрия обязательна, иначе механика связи —
правило для одной стороны, а не игра.
