# PHASE-DETECTION2 — Шкала заметности

Статус: **реализована 2026-07-05** (гейт — фоновый прогон 22 сцен; визуальная проверка
бара — владелец). Решение 2026-07-03: вместо кубиков — детерминированная шкала.

## Итог реализации

- `components.Detectability{Meter [FactionCount]float32}` на юните (FactionCount=4),
  ставится UnitFactory.
- Конвейер: воркеры считают магнитуду (`visualMagnitude` — max по каналам, гейты
  стены/терраин) и эмитят `meterEvent` (fill = 8·m²·dt) в per-worker буферы; serial
  `applyDetectMeters` берёт MAX fill на (target, faction) — порядок-независимо, пересечение
  1.0 стреляет sighting (Direct споттеру + Shared отряду + Contact), без наблюдения —
  распад 0.5/с. При полном метре воркер записывает sighting сам (как раньше).
- Магнитуда: falloff × facing × stance-conceal × **motion-mul** (стоячий 0.5 / бег 1.3) —
  неподвижность прячет, бег палит. Порог 0.5 умер: любой сигнал ≥ 0.05 копит метр ⇒
  эффективная дальность тянется к номиналу (медленный детект на краю).
- UI: `drawUnitExposureBar` — тонкая полоска над HP у юнитов игрока (оранжевая копится,
  красная = засечён), meter[FactionEnemyRed].
- Сцена `ai_los_creep`: prone+lock разведчик на 18 м — early t=3s contacts=0, детект
  между 5-10 с, вердикт PASS (contacts=1 direct=1 shared=7 early=0). Ловушка по дороге:
  враг без приказов вставал из prone — его поднимал не StanceController (override был),
  а авто-стойка unit_movement по профилю; нужен `Stance.LockUntil`.

## Суть

Мгновенный порог detect (магнитуда ≥ 0.5 → обнаружен в тот же тик) заменяется
накоплением: магнитуда наполняет счётчик заметности со скоростью f(коэффициенты),
обнаружение при заполнении, распад при потере LOS / выходе из конверта.

- **Состояние:** `Detectability [FactionCount]float32` на юните (один float на
  наблюдающую фракцию) — пишет лучший наблюдатель тика, DOD-дёшево.
- **Коэффициенты** (расширение стека 18.5 effRange × falloff × facing × concealment):
  камуфляж/снаряжение (сущности с `OwnedBy` уже есть — слоты готовы), движение
  (Speed → множитель, неподвижный prone почти невидим), опционально освещение позже.
- **UI:** индикатор «насколько я засвечен» на выбранном юните (глаз с заполнением) —
  стелс-геймплей становится читаемым. ASCII-only (шрифт).
- **Инварианты:** геометрия (стены + terrain-LOS) остаётся жёстким гейтом — шкала
  живёт только при чистом LOS; prone/hull-down из PHASE-VISION не размывается;
  replay-гейт обязателен (шкала детерминирована по построению).
- **Тюнинг:** скорость заполнения такая, что бегущий в рост на открытом ≈ мгновенно
  (сохранить текущее ощущение боя), а неподвижный камуфлированный prone в кустах —
  секунды форы.

Объём S-M. Детальные P/M — при старте фазы.
