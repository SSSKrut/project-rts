# PHASE-LOS — LOS-превью из гипотетической точки

Статус: **реализована 2026-07-19** (M1–M4; гейт replay 22/22 без регрессий — фича
render-only; визуальная проверка — владелец). Возможная оптимизация при ощутимых хичах
на пересчёте клетки: horizon-sweep вместо пошагового terrainBlocksLOS (сейчас ~2-5 мс
на пересчёт, только при смене 1м-клетки). Polish-хвост: ISSUES #14 — квады веера
утопают/парят на перепадах высот (субдивизия по дельте высот / offset по уклону).

Сквозная фича GAME-VISION §5/§6 («сразу после M0»); фича №1 жанра по исследованию 2026-07.
Keyhold-оверлей: «что видит стоящий наблюдатель из точки под курсором» + кольца дальности.

## P-решения

- **P1. Ввод:** hold **V** (свободна с input-реворков), точка = терраин под курсором
  3D-панели (готовый `mouseTargetWorldPos`/ghostTarget). Пробинг из планового вейпоинта —
  отложен к пассу редактирования маршрутов.
- **P2. Single source (урок WARNO):** вердикт видимости клетки = те же предикаты, что у
  сима — `terrainBlocksLOS` + `segmentToWallsT`/`makeLosWall` (окна/открытые двери
  прозрачны, семантика идентична `anyLosWallBlocks`), сила = `components.Falloff` канала.
  Никакой параллельной математики превью. Facing игнорируем (гипотетический наблюдатель
  свободен), высоты — stand-vs-stand (EyeHeight 1.5 → TargetCenterY 0.9 из StanceSpec).
- **P3. Развёртка:** 240 азимутов × шаг 1 м до дальности канала (кламп < ChunkSize —
  окно стен 3×3 чанка). Per-ray лимит по стенам одним `segmentToWallsT`, terrain —
  пошаговый вызов `terrainBlocksLOS` (виден дальний склон за скрытой долиной). Пересчёт
  только при смене 1м-клетки курсора / профиля. Выход — runs видимых интервалов.
- **P4. Профиль:** первый выделенный юнит с Sensors (канал с макс BaseRange), squad —
  через roster; без выделения — 40 м linear. Кольца оружия: уникальные `Weapon.RangeM`
  по выделению (Equipment.Primary).
- **P5. Рендер:** 3D — секторные квады по runs, альфа = Falloff(mid), кольцо сенсора +
  кольца оружия по терраину; карта — тот же полигон в MapRenderCtx (M4).
- **P6. Render-only:** сим не тронут; replay_gate 22/22 обязан остаться зелёным как есть.
